# Python Data Packages

The notes assemble the current python data stack: modern column-oriented storage and dataframes on top, the legacy ndarray/pandas layer below.

## Current packages

- **parquet** — a method to store data
- **polars** — "(like tibble)"; view as spreadsheet with rows/columns; origin: apache arrow

## Legacy

- **numpy** — matrices, lin alg, numerical calculations
- **pandas**
