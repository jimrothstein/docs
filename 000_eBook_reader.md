## Requirements for eBook Reader 

## Examples:
- Remarkable
- Supernote
- Other


## Requirements
- black & white (no color)
- 13.3" too big, heavy
- 8-10.3"
- Purpose:  
  -  90% read technical documents in pdf format
- Minimal distractions (no internet surfing)
- able to side-load from laptop, via usb
- files to manage software (change title, move to directory, delete etc.)
- battery:  must be sure battery is good if model is used.


## Nice to have, not required
- backlit/front light
- read handwriting (especially if replaces need to write on paper, or type on computer)
- read handwritten math and equations
- work with Calibre
- work with zotero
